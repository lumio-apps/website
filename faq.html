Help and FAQ

Quick answers to common questions.

Are the apps really free?

Yes. There are no ads, no in-app purchases and no premium version.

Do the apps need internet?

No. All features work offline. The only internet use is a button you tap yourself: "Check for updates" in every app and "Update data" in Stamply. Both only ask GitHub for a newer file, and no personal data is sent.

What data do you collect?

None. Your data stays on your device. See the Privacy Policy.

Where can I download the apps?

From each app's page and from GitHub Releases. The apps are shared only on GitHub, on purpose.

Why can't I update my app from another source?

Install the newer APK from GitHub over the old one and your data stays. If you installed a copy from somewhere else (for example an older store version), Android may refuse the update because the signing keys differ. Then uninstall first, after making a backup (PocketTally and Paperwise have Back up and Restore).

How do I move my PocketTally data to a new phone or a computer?

Open Settings, tap Back up data, save the file, and on the new phone tap Restore from backup. You can also export CSV for Excel or Google Sheets.

Android says "Install unknown apps" is blocked.

When you install an APK from GitHub, Android asks you to allow your browser or file manager to install apps. You can allow it just for this install and turn it off after.

How do I update an app?

Tap Check for updates in the app (Calculator: menu, others: Settings). It asks GitHub for a newer version and nothing else. You can also download the newer APK from GitHub Releases and install it over the old one. Your data stays.

Is Stamply's visa information always correct?

No. It is general guidance from open data, refreshed monthly. Rules change often. Always confirm with the embassy or the official government website before you travel. See the Terms and Disclaimer.

Can Paperwise change my original PDF?

No. Every tool saves a new file and leaves your original untouched.

I forgot the password of a PDF I locked in Paperwise.

Paperwise never stores passwords, so we cannot recover it. Keep your passwords safe.

Can I see the code or help?

Yes. Everything is open source on GitHub. You can report bugs, suggest features, translate or send a pull request.

How do I report a bug?

Open an issue on the app's GitHub page. See the contact page.
