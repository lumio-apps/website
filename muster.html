Muster

Why Muster

Attendance in a few clicks

Present, Absent, Half day or Leave for each worker, and mark everyone present in one tap. Holidays and weekly offs are handled for you.

Salary worked out for you

Daily, monthly or hourly pay, overtime in half-hour steps, advances recovered, bonus and fines with reasons. See the full breakdown for every month.

Stays on your computer

Worker names, phone numbers, photos and pay are stored only on this PC. No cloud, no account, nothing uploaded.

Open source

Free, with the code public on GitHub. See the repository for the license.

Features

Attendance

  • Mark Present, Absent, Half day or Leave for each worker, or mark all present at once
  • Optional check-in and check-out times, with overtime worked out automatically in half-hour steps and late arrivals flagged
  • Holidays and weekly offs set once, for the company or for each worker

Workers

  • Name, role, phone, joining date and an optional photo
  • Daily, monthly or hourly pay, each worker with their own overtime rate, hours and weekly off
  • Mark a worker inactive instead of deleting them, so old records stay correct

Salary

  • A month-by-month salary with a full breakdown
  • Advances recovered, bonus and fines with a reason, and an optional late fine
  • Holiday pay if you want it, and Mark as paid to lock the amount so it cannot change later

Reports

  • A salary slip as a PDF for each worker
  • A monthly attendance PDF
  • A salary sheet as an Excel file for your accountant

Backup and lock

  • A password-protected backup file (.mbk, AES-256-GCM). Restoring first moves your current data into a safety folder, so nothing is lost by mistake
  • A PIN lock with automatic locking when the computer is idle, a Lock now button and a recovery code
  • A lost backup password or recovery code cannot be recovered. Keep them somewhere safe
  • 70+ currencies, including INR and AMD, and safe in-app updates that check a digital signature before installing

Good to know

  • Muster is for Windows 10 and 11 (64-bit) only, and its screens are in English.
  • The PIN lock protects the Muster window, not the database file on disk. Encrypting the database is planned.
  • Hindi and other Devanagari text may not shape correctly inside PDF files yet.
  • Muster keeps your data in %APPDATA%\Muster (the database, worker photos and restore safety copies).

Private by design

Muster collects nothing. No account, no ads, no analytics and no tracking. Workers' names, phone numbers, photos, attendance and pay are stored only on your computer, and a backup is only a file you save yourself. The only network use is the optional Check for updates button, which talks to GitHub. Read the full privacy policy.

Install

  1. Open the latest release on your computer.
  2. Download Muster-vX.Y.Z-windows.zip and extract it to a folder, for example C:\Muster.
  3. Run muster.exe. There is no installer, and no administrator rights are needed.

Windows SmartScreen: Muster is free and open source, without a paid publisher certificate, so Windows may say “Windows protected your PC” the first time. Choose More info, then Run anyway. Later versions install from inside the app, and your data stays.
