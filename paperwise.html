Paperwise

Private PDF tools for Android, fully offline. Merge, split, sign, scan, compress, protect and search PDFs, all on your phone. Your files are never uploaded.

Android 7.0 or newer · Free · GitHub only

Why Paperwise

Most PDF apps upload your files, show ads or ask you to sign in. Paperwise does none of that. Every tool runs on your phone, and your files are never uploaded. The only internet use is a button you tap to check for a new version. The code is open, so you can check that yourself.

13 tools

Merge PDF

Join PDFs into one and drag them into the order you want.

Split PDF

Cut by page ranges like 1-4, 5-10 or make one file per page.

Page tools

Reorder, rotate, delete and extract pages on a visual page grid.

Image to PDF

Turn photos from the gallery or camera into a PDF: A4, Letter or fit image.

PDF to image

Save pages as JPG or PNG, all pages or just some.

Scan to PDF

Photograph paper, straighten it with four corners, pick a look and build a PDF.

Compress

Light, Balanced or Strong, with the expected size shown first.

Text from scans

Make scanned PDFs searchable, or copy their text. Offline, English.

Protect

Lock with a password (AES-128), unlock, or add a text or image watermark.

Edit and sign

Type text anywhere, draw and place your signature, add page numbers, headers and footers.

Markup

Highlighter, pen, boxes, ovals, lines and arrows in six colors.

Search in PDF

Find words inside a PDF and jump between matches.

Image privacy

Remove hidden location and device info from photos, blur faces or number plates.

Also built in

  • A PDF reader with zoom, page jump, thumbnails, Continue reading and favorites
  • Open PDFs from your file manager, chat apps or email with Open with Paperwise
  • Search and sort your files by newest, oldest, name or size
  • Light, dark or system look, in English and Hindi (हिन्दी)
  • Backup and restore in one .pwbackup file you place yourself

Good to know

  • Your original files are never changed. Every tool saves a new copy.
  • Text from scans reads English text and adds the words invisibly behind your scan, so it becomes searchable.
  • Lock, Watermark and Compress redraw each page as a picture, so text in those copies can't be selected.
  • Text you add with Edit and sign supports letters, numbers and keyboard symbols. Hindi covers the main screens.

Private by design

All PDF work happens on your phone. Paperwise has no ads, no analytics and no account. Passwords are used only to lock the file and are never stored. The internet is used only when you tap Check for updates. Text recognition uses a model bundled in the app. Read the full privacy policy.

Install

From GitHub: download the latest .apk from the Releases page, open it on your phone and allow installs from your browser or file manager when Android asks. Requires Android 7.0 or newer.

GitHub only, on purpose. To update, open Settings › Check for updates, or install the newer APK over the old one. Your files stay.
