Paperwise

Private PDF tools for Android, fully offline. Merge, split, sign, scan, compress, protect and search PDFs, and read Excel and Word files, all on your phone. Your files are never uploaded.

Android 7.0 or newer · Free · GitHub only

Why Paperwise

Most PDF apps upload your files, show ads or ask you to sign in. Paperwise does none of that. Every tool runs on your phone, and your files are never uploaded. The only internet use is a button you tap to check for a new version. The code is open, so you can check that yourself.

Also built in

  • A PDF reader with zoom, page jump, thumbnails, Continue reading, favorites and a night reading mode
  • Open PDFs, Excel sheets and Word files from your file manager, chat apps or email with Open with Paperwise, or send them and pictures from any app's Share menu
  • Save location: pick a folder in Settings and every new PDF or picture is also copied there. You can change or stop it at any time
  • Search and sort your files by newest, oldest, name or size
  • A clean, flat list look in light, dark or system mode, in English and Hindi (हिन्दी). No heavy shadows or animations, so it stays smooth on older phones
  • Backup and restore in one .pwbackup file you place yourself

Good to know

  • Your original files are never changed. Every tool saves a new copy.
  • PDF info makes a clean copy by rebuilding the PDF page by page. The text stays selectable, but bookmarks, links and form fields are not kept.
  • Text from scans reads English text and adds the words invisibly behind your scan, so it becomes searchable.
  • Lock, Watermark and Compress redraw each page as a picture, so text in those copies can't be selected.
  • Text you add with Edit and sign supports letters, numbers and keyboard symbols. Hindi covers the main screens.
  • Excel viewer shows values as they were last saved. Formulas are not worked out again, and charts, pictures, colors and merged cells are not shown. Very large sheets show the first 20,000 rows and 200 columns. Old .xls files and password-locked files cannot be opened.
  • Word viewer shows the text and layout of a document, not its exact pages. Headers, footers, footnotes, comments and page numbers are not shown. Old .doc files and password-locked files cannot be opened.
  • Save location needs a folder you pick yourself. On newer Android the main Downloads folder cannot be picked, so make a folder inside it, for example Downloads/Paperwise.

Private by design

All PDF work happens on your phone. Paperwise has no ads, no analytics and no account. Passwords are used only to lock the file and are never stored. If you pick a Save location, copies also go to that folder, and only that folder. The internet is used only when you tap Check for updates. Text recognition uses a model bundled in the app. Read the full privacy policy.

Install

From GitHub: download the latest .apk from the Releases page, open it on your phone and allow installs from your browser or file manager when Android asks. Requires Android 7.0 or newer.

GitHub only, on purpose. To update, open Settings › Check for updates, or install the newer APK over the old one. Your files stay.
