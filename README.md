# Lumio Apps website

Source of [lumio-apps.online](https://lumio-apps.online): the home page and the
pages for [Calculator](https://github.com/lumio-apps/calculator),
[PocketTally](https://github.com/lumio-apps/pockettally) and
[Paperwise](https://github.com/lumio-apps/paperwise).

Plain HTML and CSS, no build step. Hosted with GitHub Pages.

- `index.html`: home page
- `calculator.html`, `pockettally.html`, `paperwise.html`: app pages
- `style.css`: shared styles (light and dark)
- `img/`: icons and screenshots
- `CNAME`: custom domain for GitHub Pages
