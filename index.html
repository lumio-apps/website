What every Lumio app promises

  • Offline first

    Every feature works without internet. The only optional requests are "Check for updates" and, in Stamply, "Update data". Both only ask GitHub for a newer file.

  • No ads, no tracking

    No analytics, no accounts and no data collection. What you type stays on your device.

  • Open source

    All code is public on GitHub. Anyone can read it, build it or suggest a change.
