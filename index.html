The honest part

Offline first. We tell you exactly when the internet is used.

Every feature that matters works with no connection. A few apps reach out to GitHub or a public data file, only for the things below, and never send your text, files or personal data.

  • All appsAsk GitHub for a newer version when you tap Check for updates. Somno and Heliora can also check once a day, which you can switch off.
  • PeeklessTap to update its tracker list from GitHub. The list of your apps is never sent.
  • MusterOnly the Check for updates button talks to GitHub, and an update is installed only after its digital signature is verified. Worker data never leaves the PC.
  • VertoLoads its language list when it opens and downloads a pack when you tap Download. Your text is never sent.
  • StamplyLoads visa data and an exchange rate when you tap, plus an optional daily data check that is off by default.
  • AnatomoDownloads its optional 3D pack once, when you tap Download.
  • HelioraThe space station map and rocket launch list use public space-data services, only if you turn on Online features.

How I build

Open, checkable and honest.

Offline first

Every feature is designed to work with no connection. Where the internet is used, the app’s privacy page says so.

Built with Flutter

One codebase per app, for Android and for Windows. Small and smooth, even on older phones.

Open on GitHub

Source, releases and issues are public. Downloads are signed.

Updates in the app

New versions install from inside the app. Your data stays untouched.
